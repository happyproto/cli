hpy

Package repositories for hpy, the HappyProto command line.

Debian, Ubuntu

curl -fsSL https://happyproto.github.io/cli/gpg.key | sudo gpg --dearmor -o /usr/share/keyrings/hpy.gpg
echo "deb [signed-by=/usr/share/keyrings/hpy.gpg] https://happyproto.github.io/cli/deb stable main" | sudo tee /etc/apt/sources.list.d/hpy.list
sudo apt update && sudo apt install hpy

Fedora, RHEL, CentOS

sudo curl -fsSL https://happyproto.github.io/cli/hpy.repo -o /etc/yum.repos.d/hpy.repo
sudo dnf install hpy

Anything else

curl -fsSL https://happyproto.github.io/cli/install.sh | sh

For a prerelease channel, the same command with install-beta.sh or install-alpha.sh. hpy update then keeps you on the channel you installed from.

Windows

powershell -ExecutionPolicy Bypass -c "irm https://happyproto.github.io/cli/install.ps1 | iex"

Or install-beta.ps1 or install-alpha.ps1 for a prerelease channel.

Prereleases

The beta and alpha channels hold only their own releases. For apt, put the channel in place of stable in hpy.list; for dnf, download hpy-beta.repo or hpy-alpha.repo in place of hpy.repo; for the shell installer, install-beta.sh or install-alpha.sh in place of install.sh, and likewise install-beta.ps1 or install-alpha.ps1 for PowerShell. hpy channel prints the commands for switching an installed hpy.
